# Changelog

## 0.2.0 — unreleased

### Added

- Tests appear in the **Testing** view as soon as a project is opened, read from the source
  without building or running anything. They're grouped by file and class, and the list
  follows your edits as you save.
- Every test gets a pass/fail icon at its declaration, not only failing ones, and clicking a
  test opens it at its declaration.
- Each case of a parameterized test appears under its test after a run.

### Changed

- The Testing view's tree is no longer remembered between sessions; it's read from the source
  each time instead.
